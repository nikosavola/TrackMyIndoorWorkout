# Security Policy

## Supported Versions

This project is actively developed on the `develop` branch, and releases are
cut from it periodically. Security fixes are only guaranteed for the most
recent released version of the app. Older releases will generally not
receive backported security fixes.

| Version                | Supported          |
| ----------------------- | ------------------ |
| Latest release           | :white_check_mark: |
| Older releases            | :x:                 |

## Reporting a Vulnerability

If you believe you have found a security vulnerability in this repository,
please **do not** open a public GitHub issue or discuss it in a public pull
request. Instead, report it privately using GitHub's Security Advisories
feature:

**https://github.com/nikosavola/TrackMyIndoorWorkout/security/advisories/new**

This creates a private conversation with the maintainers where you can
describe the issue, and, if applicable, share proof-of-concept code or
reproduction steps. Please include as much detail as you can, such as:

- A description of the vulnerability and its potential impact.
- Steps to reproduce the issue, or a minimal proof of concept.
- The affected version(s), platform(s), and any relevant configuration.

## What to Expect

- We aim to acknowledge new reports within **5 business days**.
- We will do our best to keep you informed of progress towards a fix and
  may ask for additional information or clarification.
- Once a fix is available, we will coordinate on an appropriate disclosure
  timeline and will credit reporters who wish to be credited.

## Scope

This project is a community-maintained, open-source Flutter application.
There is no bug bounty program, and reports should be limited to genuine
security concerns (e.g. vulnerabilities that could compromise user data,
device permissions, or application integrity) rather than general bugs or
feature requests, which should be filed as normal GitHub issues.

Thank you for helping keep this project and its users safe.
